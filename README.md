# Blackjack Strategy Calculator

A Python application that simulates Blackjack strategies and exports results to a MySQL database and JSON. Visualizations are available through HTML pages.

## Features

- Core Blackjack logic
- Strategy evaluation and simulation
- Export to `.db` and `.json`
- Interactive visualizations in HTML

## Project Structure

- `main.py`: Entry point
- `blackjacklogic/`: Core game logic and strategy code
- `fileio/`: Handles DB and file operations
- `data/`: Output files

## Getting Started

```bash
pip install -r requirements.txt
python main.py
